# V1.6 independent development preview

This is a **Draft PR**, not a deployed release. Start from main V1.5.4; no Semantic Hearing model code, YAMNet weight, threshold logic, Google Forms links or production deployment changed intentionally.

## Features
1. Live page: a ten-second right-scrolling visual audio amplitude envelope drawn from the **existing** audio analyser. YAMNet-positive windows are marked red at the original capture times. The waveform is a downsampled **visual amplitude history**, not a stored audio recording; no additional microphone request, MediaRecorder, remote fetch or persistent audio store. Window color marks a model prediction and not an exact acoustic event onset.
2. AI Test Mode: "Visual waveform annotations" opens an inline editor for the selected uploaded file. Playback and 1–8x zoom, pointer/finger drag selection, numeric start/end edits, six target sound labels, event removal, and exhaustive-annotation checkbox. On save, it reuses `clip.events` and updates `clip.eventText`, `clip.labels` and `clip.complete`; the existing clip/window/event metrics and dataset split remain authoritative. Red overlays show YAMNet-positive analysis windows, teal shows manual ground truth. Hidden held-out results remain hidden before reveal.
3. Appearance: System / Light / Dark on all three pages; only the appearance choice is stored in LocalStorage, never audio. The red full-page warning retains priority.
4. Version alignment V1.6.0, syntax and Node regression CI.

## Developer verification
- `npm test`: includes original existing Node suite and `test-v16-ui.js`.
- `node --check` on modified/new JS modules.
- A real Chromium/WebKit browser and physical iPhone/iPad microphone + touch QA are **not yet validated** by merely passing Node tests.

## Manual acceptance checklist
- On iPhone Safari, deny permission: no streaming data, no false live status. Grant permission: wave moves; stop/background: data clears and mic stops. No second microphone prompt or saved audio. The YAMNet red bars must align approximately with emitted sound windows, with normal classification delay.
- Reload and switch System/Light/Dark on homepage, AI Test Mode and Microphone Test Mode. Test language switching and bright red alert contrast.
- Upload WAV, MP3 or M4A with 2 separate known events; play, zoom, drag by touch and mouse, adjust timestamps; add/edit by removing and re-adding, mark complete; check old text annotations and exported JSON/CSV match. Confirm disabled editing after hold-out final evaluation.
- Re-test original YAMNet live and AI Test Mode for regression, especially peak scores, warning timing, uploaded sample classification, dataset split and threshold persistence.

## Not implemented
No SH live separation, no actual audio recording or export of microphone input, no headset ANC access, no sound-location estimation, no upload of recordings to the server, and no true real-world detection latency measurements. The browser's decoded preview is temporary and released on close. Any performance/accuracy statements require real labelled audio, not synthetic UI tests.
